# WeatherGPT Mobile

React Native app. Scaffold with:
```bash
npx create-expo-app weathergpt-mobile
```
Wire chat screen to `POST http://<backend>:8000/query/`.
See `docs/03_UIUX_Design_Brief_WeatherGPT.md` for sky-canvas and voice-orb motion specs, and `ml/prompts/` for the exact prompts to generate each screen.
